# Our Next Chapter ❤️

An interactive cinematic love-story experience built from scratch for **Shall_We_Date**.

## Direction
- Living-space background with layered nebula atmosphere
- Depth-based starfield and pointer parallax
- Chapter-based storytelling
- Interactive memory cards
- Cinematic moonlit couple scene
- Forehead-kiss interaction
- Confession sequence
- Date proposal and date selection
- Responsive/mobile-first presentation
- Reduced-motion support

The visual direction is intentionally intimate and cinematic rather than a conventional romantic landing page.
